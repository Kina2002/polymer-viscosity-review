# 점도 검토실 — 고분자 제조 배치 검토

고분자 수용액의 점도와 제조·측정 기록을 함께 살펴보는 학습용 웹 앱입니다. **점도 숫자를 비교하는 것에 더해, 그 숫자가 어떤 조건에서 얻어졌는지 확인하고 검토 근거를 남깁니다.**

현재 첫 버전은 가상 제품 `POLY-A`와 합성 기록 **1,080건 / 270배치 / 배치당 4회 측정**을 제공합니다. 실제 제품의 규격, 물성 예측 또는 출하 승인 시스템이 아닙니다. 수치 기준은 사용자가 검토·수정할 수 있는 시연용 초안입니다.

![점도 검토실 화면](viscosity-review/docs/screenshots/desktop.png)

## 실행하기

**설치·서버 실행 없이 보려면** `viscosity-review` 폴더의 [점도_검토실_바로열기.html](viscosity-review/점도_검토실_바로열기.html)을 파일 탐색기에서 더블클릭하세요. 데이터 1,080건과 코드가 파일 하나에 들어 있습니다. 검색·기준 수정·CSV 입력·보고서 저장도 사용할 수 있습니다. 편집기에 소스가 보인다면 파일을 Chrome이나 Edge에서 여세요.

아래는 개발용 로컬 서버 실행 방법입니다.

Node.js 20 이상이 필요합니다. 이 프로젝트의 앱에는 외부 실행 패키지가 없어 `npm install` 없이 실행할 수 있습니다.

이 폴더에서 PowerShell을 열고 실행하세요.

```powershell
cd .\viscosity-review
npm start
```

브라우저에서 [점도 검토실 열기](http://127.0.0.1:4173)를 누릅니다. 서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누르세요.

이미 `viscosity-review` 폴더에 있다면 `npm start`만 실행합니다. `index.html`은 서버 주소로 접속해야 합니다. 서버 없이 열 파일은 별도의 `점도_검토실_바로열기.html`입니다.

## 첫 사용 순서

1. 전체 1,080건과 기준 충족·검토 필요 건수를 확인합니다.
2. **기준 확인 및 수정**에서 시연용 초안이 어떤 조건을 가정했는지 읽습니다.
3. **확인할 기록**의 범주나 검색·필터로 대상을 좁힙니다.
4. 측정 번호를 눌러 실제 기록과 적용 기준, 검토 이유를 확인합니다.
5. **전체 준비·측정 기록**을 펼쳐 계량부터 결과까지의 40개 항목을 읽습니다.
6. 같은 배치의 반복 측정값과 각 조건을 확인하고 검토 메모를 남깁니다.
7. **결과 CSV** 또는 **보고서 저장**으로 현재 검색·필터에 해당하는 기록을 내보냅니다.

CSV를 직접 만들어보려면 화면의 **입력 양식 CSV 내려받기**를 사용하세요. 새로고침하면 기본 시연 데이터를 표시합니다. 업로드한 파일은 다시 불러오면 동일 파일의 저장 메모를 읽을 수 있습니다.

## 구현 기능

- 합성 데이터와 CSV 입력, 배치·측정·시료 번호 검색, 상태·범주 필터, 페이지 이동.
- 기록 누락 / 입력 확인 / 제조 조건 차이 / 측정 조건 차이 / 점도 규격 이탈을 개별 표시.
- 실제 값, 기준 값과 검토 이유를 연결한 상세 화면.
- 비교 조건이 맞는 측정값만 골라 볼 수 있는 배치별 점도 그래프. 반복값을 임의로 평균 내지 않음.
- 수정 가능한 점도 규격·제조·측정 기준, 변경 시 전체 재검토와 기준 버전 기록.
- 데이터별 검토 메모와 브라우저 저장.
- 전체 기준 JSON을 포함한 CSV·Markdown 결과 다운로드.
- 데스크톱과 320px 이상의 좁은 화면 지원.

## 시연에서 살펴볼 배치

| 배치 | 준비한 상황 | 확인할 점 |
|---|---|---|
| PA-001 | 가상 기준과 일치 | 기록과 조건을 확인한 뒤 수치 비교 |
| PA-005 | 제조 온도 차이 | 제조 기록 차이와 점도 규격 이탈 구분 |
| PA-006 | 온도·속도·스핀들·읽는 시점 차이 | 좋은 숫자여도 비교 조건 확인 필요 |
| PA-007 | 필수 기록 누락 | 누락값을 0으로 채우지 않음 |
| PA-008 | 점도 수치 범위 이탈 | 가상 규격 상하한과 실제 값 비교 |
| PA-009 | 기포·평형·침지·토크 문제 | 측정 준비와 유효 범위 확인 |
| PA-010 | 복합 사례 | 한 측정에 여러 검토 항목 유지 |

핵심 판단은 **제조 차이, 측정 차이와 점도 수치 이탈을 구분**하는 것입니다. 수치상 범위 내라도 조건이 다르면 정상 결과로 확정하지 않습니다. 원인 확정과 제품 출하 승인은 사용자 업무입니다. AI 요약·조사 지원은 후속 단계이고, 이번 버전은 결정적인 코드 규칙으로 검토합니다.

기존 `problem.md`, Python 연습 코드, `연습자료`, 기획서 00~04는 이전 학습 자료입니다. 기존 액상 소재 A의 수분·함량·점도 규격과 이번 `POLY-A`의 가상 점도 규격은 서로 다른 자료입니다.
