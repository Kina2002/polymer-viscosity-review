# 고분자 점도 검토 도구 — 개발 계획과 PRD v0.1

작성일: 2026-10-02

## 목적과 사용자

고분자 화학과 QC/R&D에 관심 있는 코딩 초보자가 7일, 하루 약 2시간 동안 개발과 검증을 경험하는 포트폴리오 프로젝트다. 품질 검토자가 제조 배치의 점도와 제조·측정 기록을 함께 확인하도록 돕는 웹 앱을 만든다. Public GitHub Repository와 실행 방법, 판단 근거, 검증 결과를 최종 제출물로 준비한다.

최종 방향은 **결과 확인 → 배치 비교 → 이상 조사 지원 → R&D 활용**이다. 원인 확정, 재시험 승인, 제품 출하 승인은 자동화하지 않는다.

## 이번에 합의한 첫 버전

- 대상: 가상 고분자 수용액 A. 식별 코드 `POLY-A`로 기존 액상 소재 A 연습 자료와 구분한다.
- 최소 1,000건의 합성 측정 기록. 배치 ID와 측정 ID를 구분한다.
- 원료 계량, 제조, 보관, 측정 준비, 장비, 측정 결과의 전체 기록을 조회한다.
- 수정 가능한 기준에 따라 기록 누락 / 제조 조건 차이 / 측정 조건 차이 / 점도 규격 이탈을 구분한다.
- 기준과 실제 기록을 나란히 보여주고 검토 이유를 설명한다.
- 배치별 점도 그래프와 반복 측정 비교, 검색·필터를 제공한다.
- 검토 메모와 결과를 CSV·Markdown으로 저장한다.
- README, 검증 사례, 실제 검증 결과를 남긴다.

## 미정 사항과 개발용 가정

실제 고분자 종류, 장비 모델과 제품 SOP, 허용 범위는 아직 사용자와 확정하지 않았다. 개발을 진행하기 위해 **명시적으로 표시한 가상 기준 초안**을 사용하고 화면에서 수정할 수 있게 한다. 수치에 물리적·실무적 타당성이 검증됐다고 주장하지 않는다.

| 항목 | 시연용 초안 | 성격 |
|---|---|---|
| 점도 | 1,000~1,500 mPa·s, 경계 포함 | 가상 제품 규격 |
| 실제 측정 온도 | 25 ± 0.5℃ | 가상 시험 조건 |
| 스핀들 / 용기 / 회전 속도 | DEMO-S1 / DEMO-600 / 60 rpm | 가상 시험 방법 |
| 시료량 / 결과를 읽은 시점 | 400 mL / 회전 시작 후 60초 | 가상 시험 방법 |
| 온도 평형 / 침지 확인 / 기포 | 완료 / 표시 준수 / 육안 미관찰 | 가상 준비 요건 |
| 토크 | 10~100% | 데모 장비에 가정한 범위; 실제 모델 설명서로 교체 필요 |
| 제조 온도 / 교반 속도 / 시간 | 40 ± 2℃ / 300 ± 30 rpm / 20 ± 2분 | 가상 제조 조건 |
| 농도 | 1.00 ± 0.05 wt% | 가상 조성 |

기포 육안 미관찰은 미세 기포가 없다는 증명이 아니다. 제조 온도는 제조 중 실제 시료 온도이고, 목표 측정 온도를 제조 때부터 유지한다는 뜻이 아니다. 측정 온도는 값을 읽는 시점의 기록이므로 온도가 측정 내내 안정됐다는 증명으로 쓰지 않는다. 온도 평형 확인과 시료·측정 부품의 상태는 별도로 기록한다.

## 판단 규칙

1. 누락·해석 불가·지원하지 않는 단위는 별도 경고로 표시한다. 없는 값은 0으로 채우지 않는다.
2. 점도 수치가 범위 안에 있어도 시험 조건이 누락되거나 다르면 **수치상 범위 내, 비교 조건 확인 필요**로 표시한다. 정상 결과로 단정하지 않는다.
3. 제조 조건 차이는 제조 기록의 검토 요청이고 점도 규격 이탈이나 원인 확정과 다르다.
4. 시료 준비·장비 점검·방법 차이는 측정 조건 문제로 구분한다. 범위를 벗어났다고 회전 속도를 임의로 바꾸지 않는다.
5. 반복마다 고유 측정 ID를 사용하고, 배치·시료·반복 회차를 함께 저장한다. 연속 운전 중 시간별 읽기 기능은 이번 범위 밖이다.
6. 원본 측정값은 유지한다. 조건이 다른 값을 무조건 평균으로 합치지 않는다.
7. 기준을 수정하면 모든 기록을 다시 검토한다. 결과 내보내기에 기준 버전과 적용 수치, 데이터 출처, 메모를 포함한다.

## 데이터와 화면

1,080건 = 270개 배치 × 4회 반복 측정으로 시작한다. 합성 시나리오는 정상, 제조 차이, 측정 차이, 누락, 점도 이탈, 준비 상태 문제, 복합 사례를 포함한다. 값과 시나리오의 관계는 검토 기능을 시험하기 위한 것이며 실제 물성 예측 모델이 아니다. 기대 결과는 화면용 데이터와 분리해서 저장한다.

화면 구성: 검토 요약 / 검색·필터 / 배치 그래프 / 측정 기록 목록 / 선택한 기록의 조건·이유·메모 / 기준 설정. 모든 상태에는 색상과 글자를 함께 사용한다. 좁은 화면에서도 기록과 기준을 읽을 수 있어야 한다.

## 기술 선택과 이유

HTML·CSS·JavaScript와 Node.js 내장 기능을 사용한다. 설치할 외부 실행 의존성을 줄이고, GitHub에 올린 소스와 데이터만으로 실행할 수 있도록 한다. 계산 규칙은 화면 코드와 분리해 독립 검증한다. 서버는 로컬 정적 파일 제공만 담당하고, 업로드 파일은 브라우저에서 검토한다. 기준·메모는 브라우저에 저장하며 원본 데이터는 내보내기로 보존한다. 이 로컬 저장은 감사추적이나 공동 작업 시스템을 대신하지 않는다.

## 첫 버전 완료 기준

- 1,080건을 읽고 검색·상태 필터·개별 기록 조회를 할 수 있다.
- 합성 기대 결과와 비교한 검토가 모두 일치한다. 별도의 경계·단위·누락·잘못된 입력 사례도 통과한다.
- 잘못된 CSV는 오류를 설명하고 기존 데이터를 유지한다. 중복 측정 ID를 허용하지 않는다.
- 기준 변경과 메모 저장, CSV·Markdown 다운로드가 작동한다.
- 좁은 화면과 데스크톱에서 주요 기능을 사용할 수 있다.
- 실행 방법, 데모 기준의 한계, 검증 방법과 결과를 문서로 남긴다.

아직 완료하지 않은 사용자 결정: 가상 기준의 승인·수정, 실제 대상 제품·방법 선택, GitHub 계정과 Public Repository 공개. 개발용 초안으로 첫 버전을 먼저 실행 가능하게 만든다.

Public GitHub Repository에 첫 버전과 후속 화면 개선을 공개했다. 실험 기록·검토 기준을 나란히 보여주는 비교표와 상단 비교 안내를 추가했으며 사용자는 판정이 이해되고 이전보다 보기 좋아졌다고 확인했다.
