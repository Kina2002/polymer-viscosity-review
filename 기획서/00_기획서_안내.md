# 화학공학 전공자를 위한 QC QA AI Agent 기획서

작성일: 2026년 9월 29일  
버전: 0.1

1번 **시험결과 검토 및 이상 조사 보조 Agent**를 먼저 개발한다. 나머지 세 프로젝트는 독립적인 기획서로 보관하되, 1번에서 만든 데이터 구조와 근거 검색 기능을 재사용해 확장한다. 이번 산출물은 기획서 초안이며, 프로그램 구현이나 성능 측정 결과는 포함하지 않는다.

## 공통 기획 전제

- 기본 적용 대상은 **가상의 액상 화학 소재 A**다. 산업군이 정해지면 제품과 시험항목, 문서, 판단 기준을 교체한다.
- 초기 사용자는 개인 개발자 한 명과 시연을 보는 검토자다. 실제 생산 시스템에 연결하지 않는 학습용 시제품으로 만든다.
- 제품 규격, SOP, 시험기록과 일탈 사례는 직접 만든 모의 자료로 시작한다. 가상 수치와 문서는 화면과 보고서에서 식별할 수 있게 표시한다.
- 규격 비교와 계산은 코드가 수행한다. AI는 문서 검색, 근거 연결, 질문 제안과 문서 초안 작성을 담당한다.
- 모든 결과는 **확인된 사실, 근거, 미확인 사항, 가설, 제안**을 구분한다. 근거가 없으면 확인 불가로 남긴다.
- 규격 적합 여부의 예비 검토와 실제 제품 출하 승인은 구분한다. 문서의 최종 승인, 재시험 결정, 원인 확정과 CAPA 종결은 담당자의 업무다.
- 아래 기획서의 평가 수치는 **개발용 제안 목표**다. 현재 성능이나 법정 기준이 아니다.

## 네 프로젝트가 연결되는 방식

1. 시험 데이터나 성적서에서 검토할 사건을 찾는다.
2. 해당 사건과 관련된 SOP 및 시험기록을 확인한다.
3. 충분한 근거가 모이면 일탈 조사와 CAPA 계획의 초안을 작성한다.
4. 검토자가 수정한 내용과 확인한 근거를 기록해 다음 검토에 활용한다.

공통으로 재사용할 항목은 제품 및 로트 식별자, 시험항목 사전, 규격 버전, 문서 버전, 근거 위치, 검토 의견과 작업 이력이다. 먼저 하나의 애플리케이션 안에서 도구 호출을 연결하고, 별도 Agent 여러 개를 동시에 운영하는 구조는 필요성이 확인된 뒤 검토한다.

1번의 상세 기획서는 바로 구현 범위를 정할 수 있게 데이터 필드, 도구 역할, 예외 처리와 완료 조건을 포함한다. 2~4번은 같은 수준의 구현 세부사항을 모두 만들기보다 독립적인 문제와 MVP 범위를 명확하게 정하는 데 초점을 맞춘다.

## 산업군을 정한 뒤 바꿀 부분

배터리나 반도체 소재를 선택하면 수분, 불순물, 입도 등 대상 제품에 맞는 품질 특성과 고객 규격을 중심으로 수정한다. 석유화학이나 일반 화학을 선택하면 조성, 밀도, 점도 등 해당 제품의 시험항목과 공정 기록을 선택한다. 위 항목은 후보 예시이며, 모든 제품에 공통으로 적용되는 필수 시험항목은 아니다.

제약을 선택하면 OOS 조사와 GMP 문서 체계 등 해당 범위의 요구사항을 추가로 검토한다. FDA와 ICH 자료는 제약 확장의 참고자료이며 일반 화학 소재의 법적 기준으로 적용하지 않는다. 이 기획서 자체가 규정 적합성이나 시스템 검증을 보증하지 않는다.
