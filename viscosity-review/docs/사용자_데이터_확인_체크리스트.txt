점도 검토실 — 사용자 데이터 확인 체크리스트
작성: 2026-10-06

목적: 실제 기록과 기준을 비교하고, 화면의 검토 이유와 추가 확인 안내를 이해했는지 점검한다.
범위: 현재 합성 시연 데이터 1,080건 / 기본 가상 기준 DEMO-POLY-A-v1.
서로 다른 상황을 포함하는 대표 측정 기록 18건과 배치 비교 1개, 총 19개 점검 항목이다.
기본 기준이 바뀌면 이 문서의 기대 결과도 바뀔 수 있으므로 화면에 적용된 기준을 먼저 확인한다.

사용 방법
1. 검색창에 아래 측정 번호를 입력한다. 배치 비교는 PA-008을 검색한다.
2. '실험 기록 ↔ 검토 기준'을 펼쳐 실제 값과 기준을 비교한다.
3. 아래 기대 결과가 화면에 표시되는지, 왜 그렇게 표시되는지 설명할 수 있는지 확인한다.
4. 추가 확인 질문이 있다면 어떤 자료를 봐야 하는지 이해되는지 확인한다.
5. 확인한 항목은 이 문서의 [ ]를 [x]로 바꾸고, 이해되지 않거나 다른 결과가 보이면 메모한다.

이 목록의 체크는 프로그램 사용 점검 완료를 뜻한다.
사이트의 '자료 확인 완료' 체크는 원본 기록 등 해당 자료를 실제로 확인했을 때 사용한다.
측정 기록 앞의 보고서 체크박스는 내려받을 기록을 고르는 용도다.

진행: 1 / 19 완료. PA-007-M1은 사용자가 확인 불가 분류·메모를 작성하고 저장·모아보기 흐름을 확인했다.
다른 항목은 완료 여부를 직접 확인한 뒤 표시한다. PA-008의 검토 방향은 앞선 대화에서 함께 확인했다.
