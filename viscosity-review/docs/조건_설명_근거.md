# 체크리스트의 조건 설명

작성: 2026-10-06

사용자가 검토 항목을 왜 지켜야 하는지 이해할 수 있도록, 질문 아래에 `이 항목을 확인하는 이유`와 `달라지면 생길 수 있는 변화`를 붙인다. 수치 차이·누락의 판정과 학습 설명은 별개다. 설명은 기준 이탈의 원인 판정이나 시료의 물성 예측이 아니다.

## 제조사 자료를 바탕으로 정리한 내용

- **측정 온도·회전 속도:** 많은 액체는 측정 온도가 올라갈 때 점도가 낮아질 수 있다. 회전 속도 변화에 대한 반응은 시료마다 달라 전단박화·전단농화·속도의 영향이 없는 경우를 구분한다. [Brookfield의 온도·전단 속도 설명](https://www.brookfieldengineering.com/brookfield-university/viscosityrheology/impact-of-temperature-and-shear-rate)을 바탕으로 쉬운 표현으로 작성했다.
- **결과를 읽은 시점:** 같은 온도·스핀들·회전 속도로 계속 측정할 때 더 늦게 읽은 값은, 시간이 지나며 묽어지는 시료에서는 낮아지고 되직해지는 시료에서는 높아질 수 있다. 시간의 영향이 거의 없는 시료는 비슷한 값을 보인다. [Brookfield의 틱소트로피·레오펙시 설명](https://www.brookfieldengineering.com/brookfield-university/viscosityrheology/thixotropy-and-rheopexy)을 참고했다. 읽는 시점의 영향과 회전 속도 자체의 영향을 구분한다. 20초·60초의 비교는 학습 예시이며 가상 POLY-A가 어느 유형인지 판정하거나 점도 수치를 보정하지 않는다.
- **측정 구성·장비 상태:** 시료·용기·스핀들의 온도 안정, 스핀들과 용기 구성, 시료량·침지, 토크 범위, 수평·영점과 단위의 의미는 [Brookfield DV2T 사용 설명서](https://www.brookfieldengineering.com/-/media/ametekbrookfield/manuals/lab%20viscometers/dv2t%20instructions.pdf)의 III.2–III.3, Appendix C와 F를 참고했다. 앱의 가상 장비 코드와 기준 수치를 이 실제 장비의 사양으로 간주하지 않는다.
- **기포·교정·표준액:** 기포와 측정 준비·교정 문제는 값의 신뢰성에 영향을 줄 수 있다. [Brookfield의 정확한 점도 측정 안내](https://www.brookfieldengineering.com/-/media/ametekbrookfield/application-notes-2024/viscosity-rheology/guide-to-accurate-viscosity-measurement-_-best-practices-and-advanced-techniques_ametek_brookfield_tech_guide_released_january_2025.pdf?hash=CF3B7DB11DA28F8751839F026D9D62EE&la=en&revision=36d30653-1260-4587-929a-a35a070736b6)의 준비·교정 및 Common Challenges 부분을 참고했다. 차이 방향을 일률적으로 단정하지 않는다.
- **시간·제조 및 준비 이력·조성·균일성:** 시간, 가열·보관·교반 이력, 조성이나 균일성에 따라 결과가 달라질 수 있다는 일반 원리는 [More Solutions to Sticky Problems](https://www.brookfieldengineering.cn/-/media/ametekbrookfield/tech-sheets/more-solutions-2017.pdf?hash=09090D1ACADC9DABF6013D1D56D1310C&la=zh-cn&revision=84a81556-8cb8-4667-b3ca-821becc69ab6)의 §4.8.3–4.8.7에 근거한다. 개별 고분자 종류·배합·공정에 대한 변화 방향은 이 문헌만으로 정하지 않는다.
- **고분자 등급·농도·용해·투입·교반:** [Ashland의 Natrosol HEC 기술 자료](https://www.ashland.com/file_source/Ashland/links/PHA18-101_Natrosol_250_HEC_Formulating_elegant_liquid_and_semisolid_%20drug_products.pdf)의 PDF 9·11·14쪽을 참고했다. HEC는 등급·농도가 점도에 영향을 주며, 가루를 천천히 분산시키고 덩어리가 풀릴 때까지 교반하는 준비법을 설명한다. 농도 증가·희석, 아직 덜 풀린 증점 고분자의 용해 진행을 조건부 예시로 사용했다. 이 자료의 실제 고분자를 가상 POLY-A의 성분으로 정한 것은 아니다. 가열 중 물 손실과 농도 변화 예시는 [Ashland의 수계 컨디셔너 제조 예](https://www.ashland.com/file_source/Ashland/Documents/InCosAsia/AntipollutionConditioner.pdf)의 물 손실 보충 절차도 참고했다.
- **침지·시료량·용기·스핀들:** [Brookfield DVPlus 사용 설명서](https://www.brookfieldengineering.com/-/media/ametekbrookfield/product-manuals/dvplus-viscometer-operations-manual-m21-400.pdf)의 시료 준비·Appendix C를 참고했다. 스핀들 선택 코드, 침지 표시, 용기 구성과 온도를 맞춰 비교해야 한다. 덜 잠긴 측정부의 접촉 면적 감소나 벽·바닥 접촉 저항은 해당 상황의 물리적 설명이며, 모든 용기·스핀들 변경에 일정한 상승·하락 방향을 적용하지 않는다.

제조 온도가 높다고 나중의 점도가 반드시 낮다는 설명은 하지 않는다. 측정 온도를 다시 맞춘 후에도 열 이력에 민감한 시료에서 영향이 남을 수 있다는 문장은 시료 이력 원리를 제조 과정에 적용한 일반적인 가능성이다. POLY-A에서 그런 반응이 확인됐다는 뜻은 아니다.

40개 항목의 설명을 각각 작성했다. 온도·농도처럼 방향을 설명할 수 있는 항목은 비교할 조건과 변화 방향을 함께 적고, 기포·용기처럼 한 방향으로 정할 수 없는 항목은 변화 과정과 확인할 기록을 제시한다. 교반 속도와 점도계 회전 속도, 교반 후 휴지 시간과 회전 후 읽는 시간을 구분한다. 기록 번호·출처에는 점도 변화 대신 자료를 잘못 연결했을 때 생기는 문제와 대조할 자료를 설명한다.

## 앱의 기록 검토 원칙에 따른 설명

배치·측정·시료 번호, 장비 번호, 출처 등은 기록 추적의 이유를 설명한다. 제품 코드·점도 결과·미지원 단위의 후속 작업은 기존 검토 원칙을 설명한다. 이런 정보만으로 점도의 상승·하락을 예측하지 않는다.

기록이 누락됐어도 해당 항목의 일반 설명은 제공하되 실제 조건은 추정하지 않는다. 비교 기준이 없는 항목의 설명을 추가해도 새로운 규칙이나 합격·불합격 판정이 생기지 않는다. 정상 기록에는 기존처럼 추가 질문을 만들지 않는다. 기존 질문 ID·저장 서명·판정은 유지한다.

TXT·Markdown 보고서에는 설명과 적용 범위, 해당 설명의 출처를 포함한다. 결과 CSV의 `followUpChecklist`에는 같은 설명이 들어간다. 자료 확인 상태와 사용자 메모의 자동 저장 방법은 바꾸지 않는다.
