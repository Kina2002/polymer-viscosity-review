2026-10-06(KST)에 Sites 배포 성공을 확인했습니다. 소유자만 접근하는 배포이므로 같은 ChatGPT 계정으로 로그인해 사용합니다. 앱 설치나 개발용 서버 실행 없이 주소를 열면 됩니다. 개발용 컴퓨터가 꺼져 있어도 접속할 수 있습니다.

## 기기별로 저장되는 내용

- 배포 주소와 기본 가상 데이터 1,080건은 같은 내용을 제공합니다.
- 검토 기준 수정, 메모, 자료 확인 완료·확인 불가 상태와 이유는 각 브라우저의 로컬 저장소에 보관합니다. 기존 로컬 주소에서 작업한 내용도 배포 주소로 자동 이동하지 않습니다.
- 업로드한 CSV 자체는 새로고침 후 보관하지 않습니다. 같은 파일을 다시 올리면 그 브라우저에 저장된 검토 내용을 사용할 수 있습니다.
- 작업 결과를 보관하려면 결과 CSV와 Markdown 보고서를 내려받으세요. 내보낸 검토 내용은 기기 사이에 자동 동기화되거나 자동 복원되지 않습니다.

## 개발과 다음 배포

`npm run build:web`은 `dist/`에 정적 파일 6개만 준비합니다: `index.html`, `src/app.js`, `src/core.js`, `src/styles.css`, `data/demo-records.json`, `data/demo-records.csv`. 개발 문서·테스트·로컬 작업 자료는 웹 배포 파일에 포함하지 않습니다.

기존 `.openai/hosting.json`의 `project_id`를 재사용해 같은 사이트를 갱신합니다. GitHub의 기능 브랜치 → 검증 → PR → merge 흐름을 유지합니다. GitHub push와 merge만으로 Sites 배포가 자동 갱신되는 설정은 아직 없습니다. 앱을 변경했을 때는 같은 사이트에 별도 배포가 필요합니다. 배포용 인증 정보는 저장소에 보관하지 않습니다.
