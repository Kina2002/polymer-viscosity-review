2026-10-06 추가 결정: 사용자는 `PA-008`의 조건 기록이 같다는 점을 확인하고, **기록상 조건 차이는 발견되지 않았지만 점도는 범위를 벗어나며, 현재 기록만으로 원인을 알 수 없어 추가 자료가 필요하다**고 안내하는 데 동의했다. 이 안내는 배치 번호에 고정하지 않고, 현재 기준에서 점도 이탈만 발견된 기록에 적용한다. 누락·입력 문제·측정 또는 제조 조건 차이가 함께 있으면 기존 확인 흐름을 유지한다. 비교 기준을 설정하지 않은 항목까지 검증 완료한 것으로 표현하지 않는다.

`PA-008`의 점도는 범위 이탈 표시를 확인하려고 강제로 지정한 가상 값이다. 토크도 점도와 독립적으로 생성되어 실제 물성·조건 변화의 근거로 사용할 수 없다. 이 사례는 원인 추정 실험이 아니다. 상태를 자동으로 확인 완료 또는 확인 불가로 바꾸지 않으며, 필요한 자료를 구할 수 없는 경우 사용자가 확인 불가와 이유를 기록한다.

입력 형식·지원하지 않는 단위 등은 원본 표기를 확인하는 질문으로 연결한다. 이는 기존 입력 확인 규칙에 대한 후속 처리다. 먼저 누락·입력을 확인하고, 점도 측정 조건, 점도 수치, 제조 기록 순서로 질문을 보여준다. 모든 관련 항목은 유지한다.

## 화면과 저장에 반영한 내용

선택한 측정의 **다음 확인 질문 · 체크리스트**에서 항목 이름, 실제 기록, 적용 기준, 다음 확인 질문을 함께 표시한다. 질문은 발견한 항목에 정해진 규칙으로 연결하며 AI나 원인 예측 모델을 사용하지 않는다.

체크는 사용자가 자료를 확인했다는 표시다. 체크가 전부 채워져도 원본 기록, 가상 기준에 따른 판정, 출하 승인 상태는 변경하지 않는다. 확인한 자료·내용과 남은 질문은 검토 메모에 기록한다. 자료가 없으면 항목별 **확인 불가**를 선택하고 이유를 남길 수 있다. 사용자가 체크한 항목도 확인 불가로 바꿀 수 있으며, 이때 확인 완료 체크는 해제한다. 확인 완료·확인 불가·미확인은 서로 구분한다.

상태와 확인 불가 이유는 데이터 파일별·측정별로 브라우저에 저장한다. 원본 기록 또는 현재 기준이 저장 당시와 다르면 이전 상태를 현재 검토에 적용하지 않는다. 체크리스트 규칙의 버전도 함께 구분한다. CSV와 Markdown 보고서에 질문·근거·상태·확인 불가 이유를 내보낸다.

점도 이탈만 있는 기록의 질문을 바꾼 이번 버전에서는 해당 기록의 이전 체크 상태를 다시 적용하지 않는다. 제조·점도 측정 조건 차이 또는 누락 등 다른 문제가 있는 기록의 기존 체크는 유지한다.

## 2026-10-06 — 확인 불가 이유 분류

사용자는 기본 이유 분류를 제공하고 직접 추가·삭제할 수 있도록 요청했다. 판정의 확인 항목과 별도로 **확인 불가 이유 분류**를 만든다. 분류는 사람의 자료 확인 상태를 정리하는 용도이며 실험 조건의 원인 분류나 배치 불량 판정이 아니다.

- 기본값: 원본 기록 없음, 필요한 항목 미기록, 추가 자료 필요, 담당자 확인 대기, 기타.
- 분류 선택 전의 기존 메모는 미분류로 표시하고 내용을 보존한다. 새 필드 때문에 기존 확인 상태를 초기화하지 않는다.
- 분류 목록은 브라우저 전체에서 공유한다. 분류 삭제 시 이 브라우저에 저장된 모든 데이터 파일의 해당 메모를 미분류로 옮기며 내용·상태·서명은 보존한다.
- 이유 모아보기는 현재 데이터 전체에서 현재 기준과 원본에 유효한 확인 불가 항목만 포함한다. 다른 데이터 파일이나 다른 브라우저의 메모를 함께 집계하지 않는다.
- 이유별 건수는 체크리스트 항목 수다. 같은 측정에 확인 불가 항목이 둘 이상이면 각각 집계한다.
- 선택 분류 전체를 이유 CSV로 저장하고, 기존 결과 CSV·Markdown 보고서에도 분류와 메모를 남긴다.
