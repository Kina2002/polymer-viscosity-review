# 검토 원칙과 선택 이유

결정일: 2026-10-05. 사용자는 아래 네 가지 업무 흐름을 이해하고 납득한다고 확인했다. 이 합의는 검토 흐름에 대한 것이며, 실제 제품의 수치 규격이나 SOP를 승인한 것은 아니다. 수치는 기존 교육용 가상 기준을 유지한다.

| 발견한 상황 | 다음 확인 작업 | 선택 이유 |
|---|---|---|
| 기록이 빠져 있음 | 원본 실험·제조 기록에서 누락값 확인 | 없는 값을 추정해 넣으면 비교 근거가 사라진다. |
| 측정 조건이 기준과 다름 | 사용한 시험 방법과 실제 설정을 확인하고 재측정 필요 여부 검토 | 점도 수치가 범위 안이어도 조건이 달라지면 같은 방법의 결과로 비교하기 어렵다. |
| 제조 조건이 기준과 다름 | 해당 배치의 제조 기록과 작업 지시 확인 | 제조 차이는 확인할 기록이며, 점도 변화의 원인 확정이나 배치 불량 판정은 아니다. |
| 점도가 범위를 벗어남 | 측정 조건부터 확인한 뒤 제조 기록과 반복 측정값 검토 | 표시 수치 이탈과 측정 방법 문제를 구분하고 관련 근거를 함께 확인한다. |

입력 형식·지원하지 않는 단위 등은 원본 표기를 확인하는 질문으로 연결한다. 이는 기존 입력 확인 규칙에 대한 후속 처리다. 먼저 누락·입력을 확인하고, 측정 조건, 점도 수치, 제조 기록 순서로 질문을 보여준다. 모든 관련 항목은 유지한다.

## 화면과 저장에 반영한 내용

선택한 측정의 **다음 확인 질문 · 체크리스트**에서 항목 이름, 실제 기록, 적용 기준, 다음 확인 질문을 함께 표시한다. 질문은 발견한 항목에 정해진 규칙으로 연결하며 AI나 원인 예측 모델을 사용하지 않는다.

체크는 사용자가 자료를 확인했다는 표시다. 체크가 전부 채워져도 원본 기록, 가상 기준에 따른 판정, 출하 승인 상태는 변경하지 않는다. 확인한 자료·내용과 남은 질문은 검토 메모에 기록한다. 자료가 없으면 항목별 **확인 불가**를 선택하고 이유를 남길 수 있다. 사용자가 체크한 항목도 확인 불가로 바꿀 수 있으며, 이때 확인 완료 체크는 해제한다. 확인 완료·확인 불가·미확인은 서로 구분한다.

상태와 확인 불가 이유는 데이터 파일별·측정별로 브라우저에 저장한다. 원본 기록 또는 현재 기준이 저장 당시와 다르면 이전 상태를 현재 검토에 적용하지 않는다. 체크리스트 규칙의 버전도 함께 구분한다. CSV와 Markdown 보고서에 질문·근거·상태·확인 불가 이유를 내보낸다.
