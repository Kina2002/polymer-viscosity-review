# 합성 점도 기록 설명

`POLY-A`는 가상 고분자 수용액입니다. 실제 원료·장비·SOP를 재현하지 않습니다. 이전 연습 자료의 액상 소재 A와 구분합니다.

- 측정 기록: 1,080건.
- 제조 배치: 270개, 각 배치 4회 측정.
- 시료: 각 반복에서 별도 시료 번호를 사용한 것으로 설정.
- 생성 seed: `20261002`, 동일 생성 코드로 재현 가능.
- 원료 예시: 가상 고분자 10g + 물 990g = 총 1,000g, 농도 1wt%.
- 측정 시료량 400mL는 별도 기록이며 계량 질량과 부피를 임의로 환산하지 않음.
- 온도·속도·점도·시간과 상태 문구는 검토 동작을 시험하기 위한 값.

| 시나리오 | 측정 수 | 기대 범주 |
|---|---:|---|
| 정상 | 432 | 검토 항목 없음 |
| 제조 온도 차이 | 108 | 제조 조건 차이 |
| 측정 조건 차이 | 108 | 측정 조건 차이 |
| 필수 기록 누락 | 108 | 기록 누락 |
| 점도 범위 이탈 | 108 | 점도 규격 이탈 |
| 준비·토크 상태 문제 | 108 | 측정 조건 차이 |
| 복합 사례 | 108 | 제조 조건 차이 + 측정 조건 차이 + 점도 규격 이탈 |

조건 변경과 점도 사이의 상관·인과관계를 실제 물성으로 해석하지 않습니다. 정상 점도는 제한된 범위에서 임의 생성하고, 점도 이탈 시나리오에서는 의도적으로 다른 값을 넣습니다. 제조 온도가 높아서 점도가 반드시 변한다는 모델이 아닙니다.

`expected-results.json`은 시나리오에서 지정한 정답 범주를 보관합니다. `reviewRecord()`를 실행한 출력을 정답으로 저장하지 않습니다. 이 대조만으로 충분하다고 보지 않고, 별도의 경계·누락·단위·입력 오류 검증을 함께 수행합니다.

현재 기본 가상 기준의 전체 집계는 기준 충족 432건, 검토 필요 648건입니다. 범주별 집계는 누락 108건, 입력 확인 0건, 제조 조건 차이 216건, 측정 조건 차이 324건, 점도 규격 이탈 216건으로 중복을 포함합니다.
